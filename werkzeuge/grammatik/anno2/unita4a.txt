#lehrplan Jgst. 9 · indirekte Rede und indirekte Frage (Einleitung im Präsens)
#regel
Con il **discorso indiretto** raccontiamo quello che dice un’altra persona. Se il verbo che introduce è al **presente** (_dice, chiede, risponde_), il **tempo** del verbo **non cambia**.
| frase | «Sono stanco.» | Luca **dice che** è stanco. |
| domanda sì / no | «Hai tempo?» | Luca **chiede se** ho tempo. |
| domanda con dove, quando, perché … | «Dove lavori?» | Luca **chiede dove** lavoro. |
| imperativo | «Scrivi il curriculum!» | Luca **dice di** scrivere il curriculum. |
**Che cosa cambia?** La persona del verbo, i possessivi e i pronomi:
- _Sara: «**Il mio** capo **mi** aiuta.» → Sara dice che **il suo** capo **la** aiuta._
- _«Non **parlare**!» → Dice **di non parlare**._
- **qui → lì**: _«**Qui** fa caldo.» → Dice che **lì** fa caldo._
#regel-de
In der **indirekten Rede** gibst du wieder, was jemand sagt. Steht das einleitende Verb im **Präsens** (_dice, chiede_), bleibt die **Zeit** des Verbs gleich.
Aussage: **dice che** … · Ja/Nein-Frage: **chiede se** … (ob) · Frage mit Fragewort: **chiede dove / quando / perché** … · Aufforderung: **dice di + Infinitiv** (verneint: _di non_ + Infinitiv).
Es ändern sich Person, Possessiv und Pronomen (_io → lui/lei, mio → suo, mi → gli/le/lo/la_), außerdem _qui → lì_. Anders als im Deutschen gibt es **keinen Konjunktiv** („er sagt, er sei müde“) und **kein Komma** vor _che_.

#lehrplan Jgst. 9 · condizionale presente (Formen und Gebrauch)
#regel
Il **condizionale** si forma dall’infinito senza **-e**. Attenzione: nei verbi in **-are** la **a** diventa **e**.
| | lavor**are** | prend**ere** | dorm**ire** |
| io | lavor**erei** | prend**erei** | dorm**irei** |
| tu | lavor**eresti** | prend**eresti** | dorm**iresti** |
| lui / lei / Lei | lavor**erebbe** | prend**erebbe** | dorm**irebbe** |
| noi | lavor**eremmo** | prend**eremmo** | dorm**iremmo** |
| voi | lavor**ereste** | prend**ereste** | dorm**ireste** |
| loro | lavor**erebbero** | prend**erebbero** | dorm**irebbero** |
**Ortografia:** cercare → cer**ch**erei, pagare → pa**gh**erei · cominciare → comin**c**erei, mangiare → man**g**erei.
**Irregolari:** essere → **sarei**, avere → **avrei**, andare → **andrei**, potere → **potrei**, dovere → **dovrei**, sapere → **saprei**, vedere → **vedrei**, vivere → **vivrei**, volere → **vorrei**, venire → **verrei**, bere → **berrei**, rimanere → **rimarrei**, tenere → **terrei**, fare → **farei**, dire → **direi**, stare → **starei**, dare → **darei**.
**Uso:**
- desiderio: _**Mi piacerebbe** fare il medico._
- richiesta gentile: _**Potrebbe** ripetere, per favore?_
- consiglio: _Al posto tuo **parlerei** con il prof._
- ipotesi: _**Sarebbe** un lavoro perfetto per te._
#regel-de
Das **Konditional** bildet man vom Infinitiv ohne **-e**; bei Verben auf **-are** wird das **a** zu **e**: _lavorare → lavorerei_. Endungen: **-ei, -esti, -ebbe, -emmo, -este, -ebbero**.
Schreibung: _cercherei, pagherei_ (mit h), _comincerei, mangerei_ (ohne i).
Unregelmäßige Stämme: sar-, avr-, andr-, potr-, dovr-, sapr-, vedr-, vivr-, vorr-, verr-, berr-, rimarr-, terr-, far-, dir-, star-, dar-.
Gebrauch: Wunsch (_mi piacerebbe_ = ich würde gern), höfliche Bitte (_potrebbe …?_), Rat (_al posto tuo …_ = an deiner Stelle würde ich …), Vermutung. Das Deutsche braucht meist „würde“ + Infinitiv, das Italienische nur **eine** Verbform.

#lehrplan Jgst. 9 · Adverbien auf -mente, Adjektiv und Adverb, Wortbildung
#regel
**L’avverbio in -mente** si forma dall’aggettivo **femminile** + **-mente**:
| lento → lenta | **lentamente** |
| veloce | **velocemente** |
| facile | **facilmente** (-le → senza e) |
| regolare | **regolarmente** (-re → senza e) |
Irregolari: buono → **bene**, cattivo → **male**.
**Aggettivo o avverbio?** L’aggettivo descrive un **nome** e concorda: _una risposta **chiara**_. L’avverbio descrive un **verbo** e non cambia mai: _Sara risponde **chiaramente**._
**Formazione delle parole:**
| verbo → nome | informare → l’informa**zione** |
| aggettivo → nome | possibile → la possibili**tà** |
| mestieri | giornale → il / la giornal**ista** · lavorare → il lavora**tore**, la lavora**trice** |
| contrario | utile → **in**utile · possibile → **im**possibile · fortunato → **s**fortunato · occupato → **dis**occupato |
| di nuovo | leggere → **ri**leggere |
#regel-de
**Adverb auf -mente:** weibliche Form des Adjektivs + **-mente** (_lenta → lentamente_). Adjektive auf **-le / -re** verlieren das **e**: _facilmente, regolarmente_. Unregelmäßig: _buono → bene, cattivo → male_.
Das **Adjektiv** gehört zum Nomen und passt sich an, das **Adverb** gehört zum Verb und bleibt unverändert. Im Deutschen sehen beide oft gleich aus („eine klare Antwort“ – „sie antwortet klar“), im Italienischen nicht: _chiara – chiaramente_.
**Wortbildung:** Nomen auf **-zione** (immer weiblich), **-tà** (immer weiblich, Plural gleich), Berufe auf **-ista** und **-tore / -trice**; Gegenteil mit **in-** (vor p, b, m: **im-**), **s-**, **dis-**; **ri-** = noch einmal.

#lehrplan Jgst. 9 · Steigerung des Adverbs
#regel
Anche gli **avverbi** hanno il comparativo: **più / meno** + avverbio + **di**.
- _Luca corre **più velocemente di** Marco._
- _Oggi lavoro **meno attentamente di** ieri._
**Forme irregolari:**
| bene | **meglio** | benissimo |
| male | **peggio** | malissimo |
| molto | **(di) più** | moltissimo |
| poco | **(di) meno** | pochissimo |
_Sara canta **meglio di** me. · Devi studiare **di più**. · Studio **più di** te._
**Il più … possibile:** _Rispondi **il più presto possibile**!_
**Attenzione:** **migliore / peggiore** sono aggettivi (con un nome), **meglio / peggio** sono avverbi (con un verbo): _Cerco un lavoro **migliore**. · Adesso lavoro **meglio**._
#regel-de
Auch **Adverbien** werden gesteigert: **più / meno** + Adverb + **di** (als): _più velocemente di Marco_.
Unregelmäßig: _bene → **meglio**_ (besser), _male → **peggio**_ (schlechter), _molto → **di più**_ (mehr), _poco → **di meno**_ (weniger). Sehr gut / sehr schlecht: _benissimo, malissimo_. Vor dem Vergleichswort ohne _di_: _Studio più di te._
„So … wie möglich“: **il più** + Adverb + **possibile**.
Achtung: Das Deutsche sagt beide Male „besser“ – das Italienische trennt: **migliore** (Adjektiv, beim Nomen: _un lavoro migliore_) und **meglio** (Adverb, beim Verb: _lavoro meglio_).
